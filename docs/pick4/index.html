How 100 Grand builds its list: Family + adds 1 to each digit, takes every order, then subtracts 1-2-3-4 by position. Family − subtracts 1, every order, then adds 1-2-3-4. Mirrors flip any digits by +5. Singles give 24+24+15, doubles 12+12+15, double-doubles 6+6, trips 4+4. “Chance” is the hit rate a random list of the same size would get against the same draws.
